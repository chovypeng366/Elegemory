Elegemory 是一款以剪贴板为入口、以时间轴为组织方式的轻量速记应用。 截图、文字、待办，按下快捷键就能收好；所有内容只保存在你自己的电脑里。

全部记忆 · 按本地自然日安静地排好

记录，不需要先创建文档。

从一张截图、一个念头开始。Elegemory 把入口做得很轻，把东西留得很稳。

快捷键速记

按 Ctrl + Shift + Space 唤出速记窗口，写完回车收好，窗口自动退回。

截图直接进来

Ctrl + V 粘贴剪贴板图片，或把 PNG / JPEG / WebP 拖进窗口，自动保存到本地。

待办也能编辑

一行一件事，保存后仍可勾选、修改、增删。办完的事会被轻轻划掉。

按天排好的白板

按本地自然日分组，今天、昨天和更早的日子各自成组。整张卡片可以拖动换位。

Memory Whisper

每记下一条，页面底部会出现一句安静的情绪短句。不打扰，只是陪你一会儿。

数据留在本地

正文、待办和图片都保存在本地 SQLite 与资源目录，不需要登录，也不上传云端。

Local first

安静的工具，
不替你做决定。

Elegemory 没有账号体系，也没有远程后端。它不分析你写了什么，不会把记录同步到任何地方。 你只需要对自己的电脑负责。

  1. 01

    本地存储

    数据库与图片位于 %APPDATA%\com.elegemory.desktop，升级应用不会清空现有记录。

  2. 02

    不登录，不追踪

    没有注册、没有埋点、没有广告。断网也能正常记录和整理。

  3. 03

    删除就是删除

    记录先进入回收站；永久删除后，无引用的图片也会从你的设备上清理。

常见问题

第一次打开前，可能会想知道这些。

需要安装什么运行环境？

Windows 10 / 11 通常已自带 WebView2。如果启动后白屏，安装 Microsoft Edge WebView2 Runtime 后重试即可。

数据保存在哪里？

默认在 %APPDATA%\com.elegemory.desktop：数据库为 elegemory.db，图片在 assets 目录。删除便携版 exe 不会删除这些数据。

为什么首次运行会被 SmartScreen 拦截？

因为当前构建没有购买代码签名证书。确认文件来自本页或 GitHub Release 后，可以点「更多信息」→「仍要运行」。

关闭窗口后应用去哪了？

关闭主窗口会把 Elegemory 收进系统托盘，这是托盘应用的预期行为。要完全退出，请使用托盘菜单或设置里的「退出 Elegemory」。

以后会支持 macOS 吗？

当前优先做好 Windows。后续计划包括 macOS 适配、标签与每日回顾，以及可选的 AI 整理能力（默认关闭）。
